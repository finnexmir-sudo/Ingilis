# İngilis Dili

Azərbaycandilli öyrənənlər üçün pulsuz ingilis dili tətbiqi.
Quraşdırma tələb olunmur, internetsiz işləyir.

**Aç:** https://finnexmir-sudo.github.io/Ingilis/

## Nə var

- 1441 söz — tələffüzü Azərbaycan hərfləri ilə
- 32 qrammatika dərsi (A1–B2), 96 test sualı
- 16 səsli dialoq, 14 kölgə parçası
- Aralıqlı təkrar (SM-2), diktant, boşluq doldurma
- Monoloq məşqi, XP və nailiyyət sistemi

## Telefonda quraşdırmaq

Linki Chrome-da aç → menyu (⋮) → **Ana ekrana əlavə et**.
Proqres öz cihazında saxlanılır, heç yerə göndərilmir.
