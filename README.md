# İngilis Dili

Azərbaycandilli öyrənənlər üçün pulsuz ingilis dili tətbiqi.
Quraşdırma tələb olunmur, internetsiz işləyir.

**Aç:** https://finnexmir-sudo.github.io/Ingilis/

## Nə var

- **1441 söz** — tələffüzü Azərbaycan hərfləri ilə, 13 mövzu paketi
- **32 qrammatika dərsi** (A1–B2), 96 test sualı
- **16 səsli dialoq** — iki fərqli səslə, üç sürətdə
- **14 kölgə parçası** — uzun, təbii nitq
- **20 monoloq mövzusu** — hazır köməkçi qəliblərlə
- Aralıqlı təkrar (SM-2), diktant, boşluq doldurma, yazma testi
- XP, səviyyə, ardıcıl gün sayğacı, nailiyyətlər

## Telefonda quraşdırmaq

Linki Chrome-da aç → menyu (⋮) → **Ana ekrana əlavə et**.
Sonra internetsiz də açılacaq.

Qulaqlıqla işlətmək tövsiyə olunur.

## Məxfilik

Öyrənmə proqresi yalnız öz cihazında saxlanılır, heç yerə göndərilmir.
Tətbiqdə izləmə, kuki və reklam yoxdur.

Qeyd: sayt GitHub-da yerləşir, hər veb server kimi ziyarət qeydləri saxlanılır.
Səsləndirmə telefonun öz mühərriki ilə işləyir.

## Kod

`index.html` qurulmuş fayldır — əl ilə redaktə edilmir.
